```release-note:breaking-change
provider: `endpoint` and `token_url` no longer accept cleartext `http://` for a non-loopback host. Every request carries a credential — a bearer token, or the Ed25519-signed assertion that mints one — so on plain HTTP anyone on the network path could read it and reuse it against your estate. `http://localhost`, `http://127.0.0.1` and `http://[::1]` are still accepted, which covers an estate you reach on the machine Terraform runs on.
```

```release-note:security
provider: redirects are no longer followed off the configured origin. Go's default policy keeps the `Authorization` header across an `https` → `http` redirect to the same host, and replays a 307/308 request body — on the token endpoint, the signed client assertion — at whatever host answers. Both are now refused with an error naming the hop.
```

```release-note:security
provider: API and token responses are read under a size limit and rejected when they exceed it, rather than being read into memory unbounded. An oversized response is reported as an error; it is never silently truncated and decoded.
```

```release-note:security
build: `google.golang.org/grpc` is bumped to 1.83.2 (GHSA-2v4p-qf9q-27wj), and the `golang.org/x` modules to current.
```
